开始使用

  1. 准备自己的服务。服务应提供有效的公网 HTTPS 地址、设备鉴权、录音上传和转写结果接口。参考服务可使用部署环境中的 faster-whisper，或由服务器调用 Groq Whisper。Groq 方案需要服务端 API 密钥，无需在服务器运行识别模型；目前没有由开发者运营的默认生产服务。
  2. 填写应用设置。在手机 Connect IQ 中找到腕记的“设置”，填写 HTTPS 服务器地址和本设备访问令牌。令牌用于访问你的服务，不是 Garmin 账号密码，也不是第三方模型服务的主密钥。
  3. 保持连接。手表需要可用的网络通信路径；使用手机连接时，请保持 Garmin Connect 正常连接。录音与等待文字期间保持腕记在前台。
  4. 先用不敏感的一句话验证。确认服务能够访问、识别结果正常，再用于日常笔记。录音会发往你填写的地址，请先确认运营者及其数据处理方式。

当前目标设备为 Forerunner 570（47 mm）。手表固件必须支持应用使用的录音能力；硬件型号兼容不等于所有地区、所有固件版本均已完成实机验证。

录音与笔记

  • START：开始录音；再次按下会停止并自动发送录音进行转写。
  • 录音上限：每次最多 30 秒或 256 KiB，先到达的限制生效。WAV 格式可能更早结束。
  • BACK：在本次处理中取消并丢弃手表会话中的录音。已经到达服务器的数据不会因此被撤回。
  • 历史笔记：手表保存最近 8 条文字，每条最多 1,200 个字符。较长结果在手表上会截短，较早的笔记会被替换。
  • 删除：在笔记详情菜单中删除单条，或使用“清空本地历史”。这些操作只删除手表本地文字，不删除服务器内容。

应用仅在前台录音，不提供后台持续录音。退出应用会丢弃未完成的会话录音。转写结果可能出错，重要内容请核对后再使用。

遇到问题

提示设置未完成或服务不可用

检查 HTTPS 地址是否正确、证书是否有效、设备令牌是否与服务器一致，以及服务器和识别进程是否运行。应用不会自动替你创建云服务。

转写一直没有结果

检查手机与手表连接，并保持应用前台运行。弱网、服务器性能和模型加载都可能影响耗时。按照手表上的提示重试；若提示需要重新录音，原请求已经进入失败或不可恢复状态。

提示固件不支持录音

核对设备和固件是否支持所需录音接口。应用权限或麦克风不可用时，不会生成可用录音。请附上具体提示联系支持。

想停止使用或删除数据

停止录音并退出应用，清空本地历史，移除应用设置或卸载应用；需要彻底撤销服务器访问时，请让服务运营者轮换或撤销设备令牌。服务器文字须由运营者通过删除接口处理，或按其保留规则到期清理。卸载手表应用不会删除服务器副本、日志或备份。

WristNote support

WristNote turns short recordings you initiate on your watch into text using a service you configure.

This beta is limited to testing by the publishing account owner. It includes no default transcription service. You must supply a compatible HTTPS endpoint and device access token. Installing the app alone does not enable transcription.

Setup and use

  1. Prepare your own compatible HTTPS service. The reference implementation supports faster-whisper in your deployment environment or server-side calls to Groq Whisper. Groq requires a server-side API key but no locally running recognition model. No default production service is operated by the developer.
  2. Enter the service URL and device token in WristNote’s Connect IQ settings. Do not enter your Garmin password or a third-party provider’s master API key.
  3. Keep a working connection and keep WristNote in the foreground. Press START to record; press START again to stop and automatically upload for transcription.
  4. Verify the setup with a short, non-sensitive phrase first. The app sends audio to the address you entered.

The current target is Forerunner 570 (47 mm), with firmware supporting the required audio capture capability. Model compatibility does not establish validation on every regional firmware.

Limits and deletion

Recordings stop at 30 seconds or 256 KiB, whichever comes first. WAV recordings may stop earlier. Recording runs only in the foreground. BACK cancels the watch session; it cannot retract data already received by a server.

The watch keeps the latest eight notes, up to 1,200 characters each. Delete a note from its detail menu or clear local history. These actions affect only the watch. Server deletion, device-token revocation, logs and backups are controlled by the service operator. Uninstalling the app does not delete server copies.

Troubleshooting and contact

Check the HTTPS certificate, endpoint, token, network connection and server availability. Follow the watch’s retry or re-record message. Review important transcripts because recognition can make mistakes.
